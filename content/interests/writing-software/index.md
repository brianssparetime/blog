I've been writing software since my family got an Apple II in the 80s, and every job I've had has involved coding to some extent.

Most of what I write these days exists because some tool I was using annoyed me enough to replace it. 
 
Lately I've started using AI to accelerate what I can develop.  AI is an incredibly powerful tool for writing code, but writing code is a small part of making a great piece of software.  A clear vision, well-written documentation, and a whole of verification, testing, and iteration are still required.
